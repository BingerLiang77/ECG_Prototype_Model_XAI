# 新架构设计草稿：基于时序动态证据检索的键值对白盒心电诊断系统 (Key-Value Glass-Box Architecture)

**文档状态**：研究备忘录与未来架构草稿 (Draft & Working Proposal)  
**创建时间**：2026-10-17  
**核心思想**：打破“表格化静态拼接”的死穴，构建“当前全景锚点 + 变长动态证据检索 + 键值对样条查表”的新一代可解释心电辅助诊断范式。

---

## 一、 核心痛点与问题意识 (Core Dilemmas)

我们在 EDB 数据库系列心电图实验（Step 11 ~ Step 18）中，通过实证发现了传统白盒模型（如标准 EBM/XGBoost）处理历史心电图时的**三大结构性死穴**：

1. **缺失值与平滑阻尼困境 (Gradient Smoothing Damping)**：
   - 试图用单个表格模型统一处理“有基线”和“无基线”输入时，50% 缺失填充的中位数在树提升过程中起到了强烈的平滑阻尼作用，导致模型在面对真实基线时无法拟合出灵敏的 2D 交互曲面（AUROC 仅 0.7568，远低于独立模型的 0.8256）。
2. **两点简单差值的“时序盲区” (The 2-Point Delta Blindspot)**：
   - 单纯计算两点差值 $\Delta = x_{\text{current}} - x_{\text{baseline}}$ 只能捕捉瞬时线性漂移，无法感知多点复杂动态。
   - **典型漏诊危机（先升后降）**：在急性冠脉综合征（ACS）的自发再灌注或变异型心绞痛痉挛缓解期，ST 段经历剧烈抬高后回落至基线。此时若只算两点差值，$\Delta \approx 0$，模型将误判为“完全正常”，导致极其恶性的假阴性漏诊！
3. **横向与纵向的双重不可扩展性 (Scalability Bottleneck)**：
   - **横向多病种爆炸**：扩展至泛心血管疾病后，人类专家无法预知哪些当前特征与历史特征存在交叉依赖，人工穷举交互项失效；
   - **纵向变长序列混乱**：面对 $N \ge 3$ 份历史心电时，静态表格拼接导致特征维度急剧膨胀，矩阵千疮百孔。

## 二、 核心架构设计：解耦式证据流 (Decoupled Evidence Pipeline)

为了兼顾**“不同患者按需提取不同特征”**与**“白盒模型严密的一致性解释”**，系统解耦为两大独立模块：

```
                    【长程变长历史心电图序列】
                    [ECG_1, ECG_2, ..., ECG_t-1]
                                 │
                                 ▼
         ┌───────────────────────────────────────────────┐
         │   【模块一：时序动态证据检索器 (Evidence Selector)】 │
         │   - 架构：轻量级时序网络 (LSTM / Mamba / GRU)   │
         │   - 职责：只负责评估、挖掘历史异动与物理参数化   │
         │   - 约束：绝不输出诊断结论，严禁标签泄漏         │
         └───────────────────────┬───────────────────────┘
                                 │
                                 ▼ 导出固定 K 个【高阶证据三元组】
               ┌──────────────────────────────────────────────┐
               │ 证据 1: <ST_dev,   倒U型曲率 c2 = -0.42, 20min前> │
               │ 证据 2: <T_to_R,   回落率 85%,           20min前> │
               │ 证据 3: <PR_int,   阶梯递增速度 +15ms/h, 2天前>  │
               └──────────────────────┬───────────────────────┘
                                      │
               ┌──────────────────────┴───────────────────────┐
               ▼                                              ▼
   [当前 ECG 36维完整物理全貌]                      [动态证据槽 (K 个键值对)]
   (作为当前生理状态的主效应锚点)                     (作为时序演变的动态修饰项)
               │                                              │
               └──────────────────────┬───────────────────────┘
                                      ▼
         ┌───────────────────────────────────────────────┐
         │   【模块二：键值对白盒诊断器 (Key-Value Glass-Box)】 │
         │   - 结构：基于物理样条函数库的索引加性模型 (GAM) │
         │   - 规则：按 Feature_ID 动态路由调用专属样条曲线 │
         │   - 特性：零填零、零缺失阻尼、100% 法律级透明审核 │
         └───────────────────────┬───────────────────────┘
                                 ▼
                 【最终输出：当前状态预测 + 完整可审查证据链】
```

## 三、 模块一：多点复杂动态的高阶参数化 (High-Order Dynamic Parameterization)

针对“先升后降”等非单调演变，选择器放弃脆弱的人工业务规则，采用**客观的运动学与几何基函数投影**：

### 1. 运动学二阶曲率分解 (Kinematic Curvature Decomposition)
对历史轨迹 $(t_1, x_1), \dots, (t_n, x_{\text{cur}})$ 就地拟合抛物线展开：
$$x(t) = c_0 + c_1 \cdot \Delta t + c_2 \cdot (\Delta t)^2$$
* **$c_1$（演变速度，Velocity）**：瞬时线性漂移斜率（$\text{mV/h}$ 或 $\text{ms/h}$）；
* **$c_2$（曲率/加速度，Curvature）**：
  * **$c_2 \ll 0$（强负曲率）**：微积分上严格代表**“开口向下的倒 U 型”**，100% 精确捕捉“先升后降”的顶峰形态！
  * **$c_2 \gg 0$（强正曲率）**：代表“先降后升”的谷底形态。

### 2. 极值包络三元组 (Extrema Envelope)
直接提取临床医生视觉直觉最关注的指标：
* **最大激增幅度 (Peak Excursion)**：$\Delta_{\text{peak}} = \max_k(x_{t_k}) - x_{\text{baseline}}$
* **当前回落率 (Resolution Ratio)**：$\text{Ratio}_{\text{resolve}} = \frac{\max(x) - x_{\text{cur}}}{\Delta_{\text{peak}}} \in [0, 1]$（若等于 1 则为完全回落）
* **距峰值流逝时间 (Time-to-Peak)**：$\Delta t_{\text{peak}} = t_{\text{cur}} - t_{\text{peak}}$

### 3. 时序累积缺血负荷 (Cumulative Dynamic Burden)
$$\text{Burden} = \int_{t_0}^{t_{\text{cur}}} \max(0, \, x(t) - x_{\text{baseline}}) \, dt$$
定量刻画心肌承受异常高电压/阻滞的持续物理做功总量。

## 四、 模块二：键值对白盒模型 (Key-Value Glass-Box) 机制

### 1. 数学计算公式
模型输入由“固定的当前特征”与“动态的证据三元组”复合构成：
$$\text{Logit} = \beta_0 + \underbrace{\sum_{i=1}^{36} f_i^{\text{cur}}(x_i^{\text{cur}})}_{\text{当前心电图主效应 (36维固定)}} + \underbrace{\sum_{k=1}^K g_{\text{Key}_k}\big(\text{val}_k, \, \Delta t_k\big)}_{\text{依据证据 Key 动态调用的样条曲线}}$$

### 2. 物理样条函数库 (Physical Spline Bank)
模型内部预训练好一组透明的单变量/双变量曲线库，例如：
* $g_{\text{st\_curvature}}(c_2, \Delta t)$：针对 ST 曲率的二维评分曲面；
* $g_{\text{t\_to\_r\_rebound}}(\text{ratio}, \Delta t)$：针对 T/R 回落率的评分曲面；
* $g_{\text{pr\_drift}}(\Delta \text{PR})$：针对传导漂移的一维曲线。

### 3. 为什么能根除“平滑阻尼”？
* **未选中的特征不进入计算流**：如果患者未出现传导异常，选择器就不输出 `PR` 相关的证据；
* 白盒只对实际存在的证据计算 $g_{\text{Key}}(\cdot)$，**不需要将未选特征填入常数 0**。因此，样本矩阵中根本不存在大量坍缩为零的废弃列，彻底规避了梯度稀释与平滑阻尼！

## 六、 与 BPX-Net (*BioData Mining* 2026) 的交叉借鉴

1. **选择器的训练代理机制**：
   - 借鉴 BPX-Net 采用 KAN（Kolmogorov-Arnold Network）在 PyTorch 中可微分的特性；
   - 训练阶段可用“LSTM 选择器 + KAN 代理白盒”进行全流程端到端梯度回传，让选择器自发学会“挑选什么动态曲率能让样条拟合最优”；
2. **弱关联先验注入**：
   - 借鉴其 $p_j = \min(p_j, 1 - e_j)$ 公式，将临床专家的生理先验（如 ST-T 锚定、电轴解耦约束）以弱关联方式注入选择器，避免纯数据驱动带来的捷径偏差。

## 七、 变长心电图时序权重映射与线性白盒诊断架构 (Sequence-to-Fixed Weighting + Linear Glass-Box)

**核心设计理念**：坚决保留线性白盒（Linear Glass-Box）纯粹的数学分配律，通过时序注意力网络将“任意 1 到 $N$ 次变长心电图”无损压缩为“格式完全统一的固定维度向量”，再由线性白盒做出最终诊断与追溯。

```
患者的 1 到 N 次心电图序列
[ECG_1, ECG_2, ..., ECG_i]  (每份心电图拆解为固定的 36 维物理特征)
               │
               ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. 线性特征嵌入层 (Linear Embedding)                         │
│    - 每份心电图映射为维度固定的向量 v_j = W_emb · x_j        │
│    - 保持纯线性，杜绝跨时刻黑盒递归混洗                     │
└──────────────────────────────┬──────────────────────────────┘
                               │
               ┌───────────────┴───────────────┐
               ▼ (倒序扫描 RNN_alpha)           ▼ (倒序扫描 RNN_beta)
┌──────────────────────────────┐ ┌──────────────────────────────┐
│ 2. 心电图级权重 α_j          │ │ 3. 波形特征级权重 β_j        │
│    - 标量 Softmax 归一化     │ │    - 向量 tanh 调节权重      │
│    - ∑ α_j = 1.0 (防频次偏见)│ │    - 针对单次心电图具体特征  │
│    - 回答：哪次心电图最重要  │ │    - 回答：该次哪个指标最重要│
└──────────────┬───────────────┘ └──────────────┬───────────────┘
               │                                │
               └───────────────────────┬────────┘
                                       ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. 时序加权压缩：生成统一格式的固定维度向量 c                 │
│    c = ∑_{j=1}^i (α_j · β_j ⊙ v_j)                          │
│    - 无论心电图有 1 次还是 20 次，c 的维度永远严格锁定为 m 维 │
│    - 彻底解决变长输入无法对齐、格式不统一的难题             │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 5. 后置线性白盒模型 (Linear Glass-Box Classifier)            │
│    Logit = W · c + b                                        │
│    - 采用标准可解释线性分类器（如 Logistic 回归）做出诊断   │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 6. 100% 无损因果追溯 (Exact Auditability via Distributive)  │
│    基于乘法对加法的绝对分配律，公式完全逆向展开：            │
│    贡献度 ω_{j,k} = α_j · W(β_j ⊙ W_emb[:, k]) · x_{j,k}    │
│    - 医生可清晰审查：哪一份历史心电图、哪一个具体物理波形   │
│      为当前诊断贡献了多少正负风险分！                       │
└─────────────────────────────────────────────────────────────┘
```

### 该架构的核心优势
1. **格式严格统一**：单份心电图特征维度固定（如 36 维），经过时间轴加权压缩后输出的 $c$ 维度永远固定（如 128 维），彻底解决多份心电图输入混乱的问题；
2. **纯粹线性追溯**：因为最后一步坚持采用线性白盒，分配律 $W(A+B) = WA + WB$ 严格成立，从数学底层保证了每个时刻、每个特征贡献度的解析解无损展开；
3. **零方差平滑阻尼免疫**：由于没有强行在表格里拼接历史和填入中位数，而是沿时间轴自适应求和，完全避开了此前我们在 EBM 实验中推测的梯度阻尼陷阱。
