# 用于心电图分析的纵向可解释模型研究方案
(A Longitudinal Interpretable Model for ECG Analysis)

## 1. 研究构想 (Research Idea)

本研究的目标是构建一个具备可解释性的纵向模型，通过同时整合当前心电图（current ECG）以及变长数量的历史心电图记录（variable number of historical ECGs）来预测当前心电图的临床结局。

与将每份心电图视为独立样本的传统模型不同，本方法旨在深度利用纵向时序信息，同时在机制上保持对每份历史心电图及其具体特征的严格可追溯性（traceability）。

## 2. 拟议模型架构 (Proposed Model Architecture)

**步骤 1 — 特征提取 (Feature extraction)**

从每份心电图中提取一组固定维度（\(F\) 维）的临床或形态学特征。对于不同患者，其包含的历史心电图数量 \(T\) 可以是可变的（适应临床变长就诊记录）。

**步骤 2 — 时间维度加权 (Temporal weighting)**

采用基于交叉注意力（Cross-Attention）的机制来评估每份历史心电图与当前心电图的相关性。在所有历史心电图记录之间应用 Softmax 归一化，得到各历史时刻的时间权重 \(\alpha_t\)（满足 \(\sum_{t=1}^T \alpha_t = 1, \alpha_t \ge 0\)）。

**步骤 3 — 特征维度加权 (Feature-level weighting)**

为每份历史心电图中的每个特征独立估计特征权重 \(\beta_{t,f}\)。这些权重可取正值或负值（例如映射至 \([-1, 1]\) 区间），使模型能够精确表达不同方向（正向风险证据或反向保护/抑制证据）的信号强度。

**步骤 4 — 特征聚合 (Feature aggregation)**

跨历史心电图聚合同一特征的加权数值：

\[
z_f = \sum_{t=1}^{T} \alpha_t \beta_{t,f} x_{t,f}
\]

无论患者的历史心电图数量 \(T\) 多少，该步骤均能输出一个固定长度（\(F\) 维）的聚合特征向量 \(\mathbf{z}\)。

## 3. 备选预测模型 (Alternative Prediction Models)

根据在预测灵活性（predictive flexibility）与证据级可解释性（evidence-level interpretability）之间的权衡，拟考察两种备选预测模型。

### 方案 A — 线性模型 (Option A — Linear Model)

使用线性分类器（如逻辑回归 Logistic Regression）基于聚合特征预测当前心电图结局：

\[
\operatorname{logit}(p) = b + \sum_{f=1}^{F} w_f z_f
\]

将特征聚合公式代入后，可得到模型 logit 的严格闭式分解：

\[
\operatorname{logit}(p) = b + \sum_f \sum_t C_{t,f}
\]

其中：

\[
C_{t,f} = w_f \alpha_t \beta_{t,f} x_{t,f}
\]

在所定义的模型架构下，每个 \(C_{t,f}\) 严格代表了某份特定历史心电图中的某一具体特征对最终预测 logit 的直接数值贡献。

**优势：**
- 数学结构完全透明白盒。
- 最终预测 logit 可严格、无损地分解至单份历史记录的特征级贡献。
- 计算复杂度极低。

**局限性：** 标准线性模型若不显式引入特定交叉项，则无法自动捕捉任意非线性关系或特征间的复杂交互作用。

### 方案 B — 可解释提升机 (Option B — Explainable Boosting Machine, EBM)

使用 EBM 基于聚合特征向量 \(\mathbf{z}\) 对结局进行预测。

EBM 能够捕捉非线性特征效应以及选定的特征交互，在聚合特征层级提供更丰富的可解释性。

**优势：**
- 相比标准线性模型具有更高的模型容量与拟合灵活性。
- 能够直观揭示聚合心电图特征与预测目标之间的非线性关系（如阈值效应、饱和效应）。
- 能够显式建模聚合特征之间选定的成对交互作用（Pairwise interactions）。

**局限性：** 由于 EBM 本质是非线性的（基于样条或提升树的广义加性模型），其聚合特征的贡献通常无法通过线性模型那样简洁唯一的解析公式直接分解至单份历史心电图的具体特征贡献（若需量化单项历史证据，可能需要借助事后归因方法或额外的架构约束）。

## 4. 可解释性与证据可追溯性 (Interpretability and Traceability)

拟议架构旨在提供两个互补层级的解释能力：

- **聚合特征层级解释 (Aggregated-feature explanations)：** 识别全局哪些特征及其交互作用对当前预测起决定性影响。
- **历史证据溯源 (Historical-evidence traceability)：** 记录时间权重、特征权重、加权证据值、采集时间戳以及溯源心电图的唯一标识符。

线性模型在单项历史特征贡献与最终 logit 之间建立了直接的数学映射。EBM 则在聚合特征层级提供了更丰富的非线性解释，但若要量化单项历史证据的具体贡献，可能需要进一步结合归因方法或架构约束。

需要明确强调的是：模型自动学得的注意力权重不应直接等同于医学因果重要性，必须对其稳定性和忠实度（faithfulness）进行严格的定量评估。

## 5. 初步评估方案 (Initial Evaluation Plan)

1. 对比“仅基于当前心电图”的单截面基线模型与纵向时序模型（定量检验历史纵向信息的增益）。
2. 在预测性能指标（如 AUROC、AUPRC、Brier Score）上对比线性预测器与 EBM 的表现。
3. 评估时间权重 \(\alpha_t\) 与特征权重 \(\beta_{t,f}\) 的跨折泛化稳定性。
4. 开展消融与扰动实验：测试当移除或扰动特定历史证据时模型的响应行为（验证可解释权重的忠实度）。
5. 检验模型学得的特征效应模式与先验心电图病理生理学知识（如 ST 抬高/压低、T 波倒置动态演变）是否相符。

所有实验将严格采用患者级别划分（Patient-level data splitting），杜绝训练集与测试集之间出现跨就诊的数据泄露。

## 6. 核心科学问题 (Main Research Question)

纵向心电图模型能否通过选择性地对历史心电图及其特征进行加权来提升预测性能，同时在历史证据与最终预测之间保持完全透明、可验证的闭环联系？

当前的首要任务是确立纵向时序信息与证据选择机制的核心价值。在此基础上，我们将结合预测表现与所需的可解释性颗粒度，在由线性预测器与 EBM 所代表的两种技术路径之间做出科学决策。
